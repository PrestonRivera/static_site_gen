# Static site generator

I built this static site generator from scratch. Its used to take simple markdown files and turn them into a static website(a mix of HTML and CSS files)

## Installation

### Clone the project

- `git clone https://github.com/PrestonRivera/static_site_gen.git`

### Run the project 

- `./main.sh`

### Create your own static site

Using the `/content/index.md` and `/content/majesty/index.md` files you can create your own static site with easy to write Markdown.
Once you've added the information you would like to host run `./main.sh` and your static site will run on `http://0.0.0.0:8888/`.
